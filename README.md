I'm an **Electronics & Computer Engineering** student at Amrita Vishwa Vidyapeetham, Bengaluru, building intelligent, data-driven applications where software meets machine learning.

- 💼 Previously **Software Intern @ Samsung PRISM**, working on computer vision for an autonomous chess-playing robot
- 📄 Published at **IEEE**: severity detection of Chronic Fatigue Syndrome with XGBoost & Graph Neural Networks
- 🎤 **President, Microsoft Ignite Student Club**, where I launched *MSpectra* to grow our campus coding culture
